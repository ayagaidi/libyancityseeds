# Language examples

All examples use the same stable endpoint:

```text
https://raw.githubusercontent.com/ayagaidi/libyancityseeds/v1.1.0/data/municipalities.json
```

No API key or SDK is required.

- [JavaScript](javascript-fetch.js)
- [TypeScript](typescript.ts)
- [Python](python.py)
- [PHP](php.php)
- [Go](go.go)
- [C# / .NET](csharp.cs)
- [Dart / Flutter](dart.dart)
- [Swift](swift.swift)
- [Java](java.java)

For production, keep the version tag in the URL so dataset upgrades are intentional.
