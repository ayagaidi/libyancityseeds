# Libya Locations v1.1.0 🇱🇾

**Release date:** 2026-09-07

`v1.1.0` makes Libya Locations easier to integrate from **any programming language or framework** without changing the stable location record shape introduced in v1.0.0.

## Universal integration

The project now treats JSON and CSV as the primary public interface. No SDK, API key, Laravel installation, or package manager is required.

Production applications can consume versioned files directly:

```text
https://raw.githubusercontent.com/ayagaidi/libyancityseeds/v1.1.0/data/municipalities.json
https://raw.githubusercontent.com/ayagaidi/libyancityseeds/v1.1.0/data/cities.json
```

## Added

- `data/endpoints.json` for programmatic discovery of datasets and stable URLs
- `schemas/location.schema.json` using JSON Schema Draft 2020-12
- full language-agnostic integration guide
- examples for JavaScript/TypeScript, Python, PHP, Go, Java, C#/.NET, Dart/Flutter, and Swift
- guidance for remote fetching, caching, bundled/offline use, and database imports
- CI validation for endpoint metadata and the universal record contract

## Stable data contract

No breaking schema change was introduced. Each record remains:

```json
{
  "id": 94,
  "slug": "tripoli-center",
  "name_ar": "طرابلس المركز",
  "name_en": "Tripoli Center",
  "type": "municipality"
}
```

## Dataset

- 141 municipalities
- 50 cities/place records
- Arabic and developer-friendly English display names
- JSON and CSV exports
- Laravel seeders remain available as an optional integration path

## Recommended production usage

Pin `v1.1.0` in the raw GitHub URL, cache the response, and use stable slugs for integration identifiers. Upgrade to newer dataset versions intentionally after reviewing the changelog.
