# Libya Locations v1.0.0 🇱🇾

**Release date:** 2026-09-07

`v1.0.0` is the first stable open-data release of the rebuilt `libyancityseeds` repository.

The project now provides reusable Libya location data for Laravel applications, APIs, mobile apps, forms, delivery systems, e-commerce, banking, and other software that needs Arabic/English municipality or city values.

## Dataset

### Municipalities

- 141 municipality records
- Arabic names from the Libyan Ministry of Local Government municipality directory baseline
- developer-friendly English transliterations/display names
- stable slugs
- JSON and CSV formats

### Cities

- 50 city/place records migrated from the repository's original `CitySeeder.php`
- Arabic and English display names
- stable slugs
- JSON and CSV formats

Cities and municipalities remain separate datasets because they are not interchangeable administrative concepts.

## Laravel support

- `LibyaMunicipalitySeeder`
- `LibyaCitySeeder`
- idempotent `upsert` behavior
- migration example
- localized API example
- backward-compatible modernization of the original `CitySeeder.php`

## Other developer usage

- direct JSON consumption
- CSV exports
- JavaScript fetch example
- dataset manifest with counts and source metadata

## Data quality

GitHub Actions validates:

- valid JSON/UTF-8
- required fields
- unique and contiguous IDs
- unique stable slugs
- correct record types
- JSON/CSV parity
- manifest counts

The `master` branch passed this validation before the release was prepared.

## Source and naming notes

The municipality Arabic-name baseline is documented in `DATA_SOURCES.md` and points to the public municipality directory of the Libyan Ministry of Local Government.

English names are maintained as developer-friendly transliterations. They are not asserted to be official government English spellings, and contributions with reliable references are welcome.

## Not included yet

The first stable version intentionally does not include coordinates, population, postal codes, electoral codes, or municipal subdivisions (`محلات`). Those fields need a reliable source and maintenance strategy before becoming part of the stable schema.
